# Security policy for TrueSync Connector

## Supported versions

Report issues against the latest release on the default branch.

## What to report

- Remote code execution, credential theft, or privilege escalation in the connector
- Pairing secret leakage (DPAPI / Keychain misuse)
- Ways to print to another shop’s printers without authorization

## What not to include in public issues

- Pairing codes, device secrets, API keys, AWS/Firebase credentials
- Customer documents or shop data

## Contact

Open a private security advisory on the public repository when available, or contact the maintainers **SandHut** and **Nandakishore Gowda G** (see README). Do not open a public issue with exploit details until a fix is ready.
